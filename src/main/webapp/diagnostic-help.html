🔧 Diagnostic et Aide Login

⚠️ Problème détecté: Le système ne peut pas trouver d'utilisateur avec l'email admin@gmail.com en base de données.

📋 Étapes de Résolution

✅ Étape 1: Lancer le Diagnostic Complet

Cliquez sur le bouton ci-dessous pour afficher un diagnostic détaillé de votre base de données:

Ouvrir Diagnostic Complet 🔍

Cela affichera le contenu exact de votre table utilisateur et les erreurs éventuelles.

✅ Étape 2: Vérifier la Base de Données (MySQL)

Connectez-vous à MySQL avec phpMyAdmin ou MySQL CLI et exécutez:

-- Voir tous les utilisateurs SELECT id_user, username, mot_de_passe, role, email FROM utilisateur; -- Compter les utilisateurs SELECT COUNT(*) FROM utilisateur;
⚠️ Si aucun résultat: La table est vide, allez à l'étape 3

✅ Étape 3: Ajouter des Utilisateurs de Test

Si la table est vide, exécutez ce SQL dans phpMyAdmin:

-- Créer l'utilisateur ADMIN INSERT INTO utilisateur (username, mot_de_passe, role, email) VALUES ('admin', 'admin123', 'ADMIN', 'admin@gmail.com'); -- Créer l'utilisateur ETUDIANT INSERT INTO utilisateur (username, mot_de_passe, role, email, num_etudiant) VALUES ('student', 'student123', 'ETUDIANT', 'student@gmail.com', 'E001'); -- Vérifier l'insertion SELECT * FROM utilisateur;
✓ Après exécution: Vous devriez voir 2 utilisateurs dans le tableau.

✅ Étape 4: Vérifier le Format des Données

Assurez-vous qu'il n'y a pas d'espaces avant/après l'email ou le mot de passe:

-- Voir les données avec des pipes pour détecter les espaces SELECT id_user, CONCAT('|', TRIM(email), '|') as email, CONCAT('|', TRIM(mot_de_passe), '|') as password, role FROM utilisateur;

Si vous voyez des espaces entre les pipes, exécutez la commande de nettoyage ci-dessous.

✅ Étape 5: Nettoyer les Espaces (si nécessaire)

Si vous trouvez des espaces, exécutez ceci pour les supprimer:

-- Nettoyer les espaces UPDATE utilisateur SET email = TRIM(email), mot_de_passe = TRIM(mot_de_passe), username = TRIM(username), role = TRIM(role); -- Vérifier après nettoyage SELECT * FROM utilisateur;

✅ Étape 6: Redéployer et Tester

Après avoir ajouté/nettoyé les données:

  1. Redéployez l'application (Clean + Build + Redeploy)
  2. Redémarrez Tomcat
  3. Allez sur http://localhost:8080/exemplaire/login.jsp
  4. Entrez:
    • Email: admin@gmail.com
    • Mot de passe: admin123
  5. Cliquez sur "Se connecter"
